## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The draft of gemSpec_DiPag_FD changes A_27411 to A_27411-01: the DiPAG Fachdienst's processing context authenticates itself to clients with the identity oid_dipag-vau (1.2.276.0.76.4.323) and the certificate profile C.FD.AUT (oid_fd_aut), no longer C.FD.ENC (gemSpec_DiPag_FD 1.1.2). gemSpec_OID 3.26.0 Tab_PKI_406 already allows oid_dipag-vau on C.FD.AUT only, and rust/ti-pki/src/oid.rs:329 has it so. ti-pki has no profile for it: rust/ti-pki/src/profile.rs knows epa-vau-aut and zeta-guard-aut as the role-selected C.FD.AUT profiles, so automatic selection reports a DiPAG VAU certificate as unclaimed and ti pki verify cannot be asked for it by name.
