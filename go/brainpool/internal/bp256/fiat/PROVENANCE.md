# Provenance: brainpoolP256r1 field arithmetic

Four files in this directory are **generated, machine-checked code**, committed
verbatim and never hand-edited:

| file | field | emitted by |
|---|---|---|
| `p_fiat64.go` | mod p (field prime) | [Fiat Cryptography](https://github.com/mit-plv/fiat-crypto) |
| `p_invert.go` | mod p | [addchain](https://github.com/mmcloughlin/addchain) |
| `n_fiat64.go` | mod n (group order) | Fiat Cryptography |
| `n_invert.go` | mod n | addchain |

`element.go` (`Element`, mod p) and `scalar.go` (`Scalar`, mod n) are the
hand-written wrappers, adapted from the Go standard library template
`crypto/internal/fips140/nistec/fiat`; `ct.go` holds the two constant-time
helpers they share.

## Why this is the "formally verified" layer

Fiat Cryptography synthesizes field arithmetic from a Coq proof that the emitted
code computes the correct modular result for every input within the documented
bounds. This is the same provenance the Go standard library relies on for its
P-224/P-256/P-384/P-521 field elements. We reuse the **identical toolchain,
image, and flags** the standard library uses, changing only the modulus.

## Moduli

brainpoolP256r1, RFC 5639 §3.4:

    p = 0xA9FB57DBA1EEA9BC3E660A909D838D726E3BF623D52620282013481D1F6E5377
    n = 0xA9FB57DBA1EEA9BC3E660A909D838D718C397AA3B561A6F7901E0E82974856A7

Neither has a special reduction structure (unlike the NIST Solinas primes), so
the general **word-by-word Montgomery** synthesizer is the correct choice, with
4 limbs of 64 bits.

## Reproducing

The generator runs inside the pinned `fiat-crypto:v0.0.9` image — the exact
image and commit the Go standard library pins (see
`$GOROOT/src/crypto/internal/fips140/nistec/fiat/Dockerfile`):

```dockerfile
FROM coqorg/coq:8.13.2
RUN git clone https://github.com/mit-plv/fiat-crypto && cd fiat-crypto && \
    git checkout 23d2dbc4ab897d14bde4404f70cd6991635f9c01 && \
    git submodule update --init --recursive
RUN cd fiat-crypto && eval $(opam env) && make -j4 standalone-ocaml SKIP_BEDROCK2=1
ENV PATH /home/coq/fiat-crypto/src/ExtractionOCaml:$PATH
```

Build it once, then run the driver in this directory for each field:

```sh
docker build --platform linux/amd64 -t fiat-crypto:v0.0.9 .
go install github.com/mmcloughlin/addchain/cmd/addchain@v0.4.0
go run generate.go -field p
go run generate.go -field n
```

- fiat-crypto: commit `23d2dbc4ab897d14bde4404f70cd6991635f9c01` (release v0.0.9)
- addchain: v0.4.0
- machine word size: 64
- requested operations: `mul square add sub one from_montgomery to_montgomery selectznz to_bytes from_bytes`

The exact `word_by_word_montgomery` invocation is recorded in the
`Autogenerated:` header comment at the top of each `*_fiat64.go`.
