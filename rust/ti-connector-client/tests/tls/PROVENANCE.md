# Provenance

TEST-ONLY TLS material for the ureq transport's tests (`tests/tls.rs`, `check.rs`,
`probe.rs`, and ti-cli's `tests/connector.rs`), generated by `generate.sh` with OpenSSL,
never by Rust code: random P-256 keys under a self-made CA, no relation to any TI PKI.
What each file is, `generate.sh` lists at its top.

- Source: `generate.sh` in this directory.
- Version: added in 7df40085 (2026-09-27); the OpenSSL version used is not recorded.
  Validity is fixed from 2026-01-01 to 2036-01-01, so the files do not go stale.
- Refresh: `./generate.sh` here. It writes new keys, so every file changes; the
  tests read the files and pin no digest of them.
