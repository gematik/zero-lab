# Provenance

TEST-ONLY TLS material for the Konnektor's TLS (`tests/check.rs` here, ti-tls's
`tests/konnektor.rs`, ti-client's `tests/konnektor_tls.rs` and `tests/konnektor_check.rs`,
ti-cli's `tests/connector.rs`), generated by `generate.sh` with OpenSSL, never by Rust code: P-256 keys under a self-made CA, no relation to any TI PKI.
What each file is, and which outputs are randomised, `generate.sh` lists at its top.

- Source: `generate.sh` in this directory.
- Keys: `keys/` (`ca.key`, `other.key`, `client.key`) and `server-key.pem` are the committed TEST-ONLY
  keys; `client.key` is the key that was inside `client.p12` before the switch to stable data.
  Validity is fixed from 2026-01-01 to 2036-01-01, so the files do not go stale.
- Refresh: `./generate.sh` here writes only what is missing; `FORCE=1 ./generate.sh` writes all files
  again from the same keys. Only the two `.p12` files change bytes (PKCS#12 salts and IVs are random);
  the tests read the files and pin no digest of them.
