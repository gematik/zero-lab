# Generated test PKI

Every file here is generated by OpenSSL, an implementation independent of ti-pki, from the
scripts next to it; the keys exist only in a temporary directory while a script runs. All
certificates are TEST-ONLY and valid around the fixed instant `TestPki::NOW`
(2026-01-01T00:00:00Z), so they do not go stale.

| Path | Generator | What |
| --- | --- | --- |
| `*.pem` | [`generate.sh`](generate.sh) | roots, CAs and end entities for chain building, path validation, the validity models, OCSP responders and the A_28419 cross certificates; the script's header has the topology |
| `ocsp/*.der` | [`generate.sh`](generate.sh) with [`ocsp.sh`](ocsp.sh) | OCSP responses produced at `NOW`, assembled from DER pieces and signed with `openssl dgst`, since `openssl ocsp` can neither back-date a response nor add the certHash extension |
| `types/*.pem` | [`generate.sh`](generate.sh) | end entities for certificate-type detection and the gemSpec_PKI type baselines, transcribed in the script independently of `src/cert_type.rs` |
| `tsl-signer/*.pem`, `tsl-signer/ocsp/*.der` | [`tsl-signer/generate.sh`](tsl-signer/generate.sh) | a TSL signer CA (GEM.TSL-CA99 TEST-ONLY) and C.TSL.SIG signers each breaking one rule of `spec/tsl-xmldsig` part B, and OCSP answers about the signer |

First generated in `b8175079` (2026-09-23); the files as committed are the output of the
scripts as committed, last changed on main by `12dbc435` (2026-11-03). The OpenSSL version
used is not recorded; it needs brainpool curves.

The corpora under `spec/pki-path/testdata` and `spec/pki-profiles/testdata` are made from
these files.

## Refresh

From `rust/`: `just test-pki` runs both scripts. Every certificate gets a new key, so the
corpora change: rewrite them with `TI_PKI_BLESS=1 cargo test -p ti-pki --all-features`,
run `cargo test -p ti-pki --all-features`, and run `go/tipki`'s tests against the new
corpora before committing.
